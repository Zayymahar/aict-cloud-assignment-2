# Average Sensor Readings (CS-117 Assignment 2)

## Purpose
A small Python program that calculates the count, minimum, maximum and
average of a list of sensor readings. Made for CS-117 Applications of ICT,
NUST SEECS.

## Readings
[22, 24, 26, 28, 30]

## Expected Output
```
Count: 5
Minimum: 22
Maximum: 30
Average: 26.0
```

## How to Run
Run `python main.py` (Python 3), or paste the code into a cell in
Google Colab (colab.research.google.com) and run it.
